# 兼容 TCP_ESTUN 代码开发流程

## 1. TCP 8888 解析入口

`CodroidApi/src/RobotDemo.cpp`

```text
TCP JSON
  → 合法性校验
  → 按 type 分流：type1 示教 / type2 查询 / type3 删除
  → type1 只开启示教，并保存 point_type：缺省=普通，0=AprilTag，1=ICP
  → mechanical_arm_command 只携带 command：1 记录 Ref，2..N 记录 Work
```

严格边界：`point_type` 只允许出现在开始示教的 `type1`；记录报文不得再次携带 `point_type`。

## 2. Type1 示教录制

配置：`config/tagtask.json`

- `tag_size_mm`：Tag 黑色外框边长，单位 mm。
- `handeye_json`：手眼标定入口，提供 `T_flange_camera`。
- `tcp_calibration_json`：TCP 标定入口，供后续执行时做末端偏移补偿；Type1 录制不参与变换计算。

### 2.1 普通点（无 `point_type`）

- 开始：
```json
{"type":"type1","mapid":"M","poseid":"P"}
```
startTeaching()` 开始拖拽并创建 `mapid/poseid`。
- 记录：
```json
{"type":"mechanical_arm_command","mapid":"M","poseid":"P","command":1}`
```
normalRecord()` 读取机械臂 `angle + pose`，保存为 `N.json`。

### 2.2 AprilTag 点（`point_type=0`）

Ref：

```json
{"type":"type1","mapid":"M","poseid":"P","point_type":0}
{"type":"mechanical_arm_command","mapid":"M","poseid":"P","command":1}
```

1. 图像：`D455Camera.startColorOnly()` 预热 → 机械臂连续停稳 2 s → `captureColorOne()` 丢弃旧帧，输出一帧 `D455Frame`（BGR、内参、畸变、时间戳）。
2. 识别：`TagTask::recordReference(mapid, poseid, frame, tag_id, error)` 输入彩色帧和 `tag_id`，按旧 ROS2 角点顺序调用 `solvePnP()`，得到 `T_camera_tag`。
3. 位姿：`normalRecord()` 保存 `angle + pose`；`TagTask` 读取手眼标定，计算 `T_base_tag = T_base_flange * T_flange_camera * T_camera_tag`，写入 `1.json/tag_pose`。

Work：

```json
{"type":"mechanical_arm_command","mapid":"M","poseid":"P","command":2}
```

停稳 2 s → `normalRecord()` 保存当前 `angle + pose` → `TagTask::recordWork()` 写入 `trans = inv(T_base_tag_ref) * T_base_flange_work`。Work 不开相机。

### 2.3 ICP 点（`point_type=1`）

Ref：

```json
{"type":"type1","mapid":"M","poseid":"P","point_type":1}
{"type":"mechanical_arm_command","mapid":"M","poseid":"P","command":1}
```

停稳 2 s → `D455Camera.start()` 按需启动彩色+深度 → `captureOne()` 获取 5 帧新点云 → `normalRecord()` 保存 `angle + pose` → `IcpTask::recordReference()` 融合并保存 `1_20mm.ply, 1_10mm.ply, 1_5mm.ply`。

Work：

```json
{"type":"mechanical_arm_command","mapid":"M","poseid":"P","command":2}
```

停稳 2 s → `normalRecord()` 保存当前 `angle + pose` → `IcpTask::recordWork()` 写入 `trans = inv(T_base_flange_ref) * T_base_flange_work`。Work 不开相机。

Type1 已接入 `RobotDemo.cpp` 的正式 TCP 响应；报文字段会校验，视觉记录中途失败会清理本次 command 的不完整文件。

## 5. 生产入口与执行边界

`CodroidApi/src/RobotDemo.cpp` 现为唯一生产入口：TCP 8888 解析、Type1 示教、AprilTag/ICP/普通点执行和 Codroid 控制均在同一进程内，不依赖 ROS2。

- 机械臂空站点 `command=1..6`：复位、上电、下电、开始拖拽、结束拖拽、清除报警。`command=7` 未定义，明确返回 `failed`。
- 到点条件：六轴中最大关节残差 `<=0.5 deg`，并连续保持 `0.5 s` 才进入下一步。AprilTag、ICP、普通点和复位统一此条件。
- ICP 执行固定回正 2 步：每步到点稳定后丢弃 3 帧新点云，再匹配并运动；第二步到点后直接执行 Work，不再用 `2 mm / 0.2 deg` 判定收敛。内点数、重叠率、RMSE 和单步最大修正量仍作为坏匹配保护。
- `type2` 结束当前示教时：`ToAuto -> 复位 -> 到点确认 -> 查询`。
- 站点执行失败时：`stopMov -> ToAuto -> 复位`，仍返回 `status=failed`；复位后由外部调度进入下一任务，不会把失败伪报成 `done`。
- 新请求正在执行时，后到请求直接返回 `busy`，不排队，避免旧命令在之后突然执行。

点位固定保存在 `TCP_asdun_arm/records/M/P/N.json`，由 `config/tagtask.json` 的 `record_root` 统一指定。

```bash
cd /home/nvidia/Robot_Arm_Project/TCP_asdun_arm/CodroidApi
./compileDemo.sh
./runDemo.sh
```
