# cc机械臂示教使用说明

## 功能概述

允许用户通过示教录点的方式记录机械臂动作，并在任务执行时自动触发相应的机械臂动作。系统支持TCP/IP通信控制方式。

## 系统架构

```
示教录点 → 任务创建 → 任务执行 → 机械臂动作触发
    ↓         ↓         ↓           ↓
  前端界面   任务管理   导航系统    机械臂控制
    ↓         ↓         ↓           ↓
 录点管理   动作配置   状态监听    TCP/ROS通信
```

## 核心功能

### 1. 示教录点功能
**录点操作**：在示教管理页面点击"录点"按钮
**点位命名**：支持自定义示教点名称
**自动发送**：录点成功后自动通过TCP发送给NX系统
**降级处理**：支持多种发送方式的智能降级

### 2. 任务集成功能
**动作配置**：在任务创建时添加机械臂动作
**自动触发**：机器人到达导航点时自动执行机械臂动作
**状态监控**：实时监控机械臂执行状态
**错误处理**：完善的错误处理和重试机制

### 3. 机械臂控制功能
**TCP通信**：与NX板进行TCP/IP通信
**ROS话题**：通过ROS话题发布机械臂命令
**脚本调用**：调用tcp_ros_demo.sh脚本执行动作
**状态管理**：管理机械臂运行状态和点位信息

## 使用流程

### 1. 示教录点流程

#### 1.1 进入示教管理页面
1. 打开系统主界面
2. 点击"示教管理"菜单
3. 进入示教管理页面

#### 1.2 执行录点操作
1. 点击"录点"按钮
2. 输入示教点名称（支持数字、英文、下划线）
3. 点击"确定"开始录点
4. 系统自动：
   - 记录当前机器人位置
   - 生成示教点ID
   - 通过TCP发送给NX系统
   - 显示录点结果

#### 1.3 录点数据格式
```json
{
  "type": "",
  "mapid": "当前地图ID",
  "poseid": "录制的示教点ID",
  "timestamp": "",
  "sequence":
}
```

### 2. 任务创建流程

#### 2.1 创建新任务
1. 进入"任务创建"页面
2. 填写任务基本信息
3. 添加导航点
4. 为导航点配置机械臂动作

#### 2.2 配置机械臂动作
1. 选择导航点
2. 点击"添加动作"
3. 选择动作类型为"机械臂"
4. 填写机械臂动作参数：
   - **点位ID**：与示教录点时的poseId一致
   - **执行时机**：完成任务时或开始前
   - **动作类型**


### 3. 任务执行流程

#### 3.1 启动任务
1. 选择要执行的任务
2. 点击"开始执行"
3. 机器人开始导航到第一个点位

#### 3.2 自动触发机械臂动作
1. 机器人到达导航点
2. 系统检查是否有机械臂动作
3. 如果有，自动执行机械臂动作：
   - 获取当前地图ID
   - 调用机械臂控制器
   - 发送TCP消息给NX系统
   - 等待机械臂动作完成

### 2. 后端组件

#### 2.1 机械臂控制器 (`mechanical_arm_controller.py`)
```python
class MechanicalArmController:
    def __init__(self, nx_host="192.168.2.100", nx_port=8888):
        self.nx_host = nx_host
        self.nx_port = nx_port
        self.tcp_socket = None
        self.tcp_connected = False

    def send_navigation_point_reached(self, map_id, point_id):
        """发送机器人到达导航点的消息"""
        message = {
            'mapid': str(map_id),
            'poseid': str(point_id),
        }
        return self._send_message(message)

    def execute_navigation_point_action(self, map_id, point_id):
        """执行导航点对应的机械臂动作"""
        success = self.send_navigation_point_reached(map_id, point_id)
        if success:
            time.sleep(5)  # 等待机械臂完成动作
        return success
```

#### 2.2 导航状态监听 (`master_node_subscriber.py`)
```python
def _trigger_mechanical_arm_action(self, status_type):
    """触发机械臂动作"""
    current_task = self.master_node.current_task_info
    mechanical_arm_action = self._get_current_mechanical_arm_action(current_task)

    if mechanical_arm_action:
        map_id = self._get_current_map_id()
        arm_point_id = mechanical_arm_action.get('pointId')
        success = self.mechanical_arm_controller.execute_navigation_point_action(map_id, arm_point_id)
```

## 故障排除

### 1. 录点失败
**问题**：点击录点按钮后没有反应
**解决方案**：
- 检查机器人是否处于示教模式
- 确认地图已加载
- 检查网络连接状态

### 2. TCP发送失败
**问题**：录点成功但TCP发送失败
**解决方案**：
- 检查NX板网络连接
- 确认IP地址和端口配置正确
- 查看系统日志获取详细错误信息

### 3. 机械臂动作不执行
**问题**：机器人到达点位但机械臂不动作
**解决方案**：
- 检查任务配置中的机械臂动作
- 确认点位ID与示教录点ID一致
- 检查机械臂控制器状态

### 4. 任务执行中断
**问题**：任务执行过程中中断
**解决方案**：
- 检查机械臂执行状态
- 确认NX板响应正常
- 查看执行日志定位问题
